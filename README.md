# SBDC Business Assessment Tool

An AI-powered business assessment tool built for the Wisconsin Small Business Development Center (SBDC). Users answer questions across 6 functional areas, select a business catalyst, and receive personalized recommendations generated by Google Gemini AI — along with a downloadable PDF report.

---

## Tech Stack

- **Backend:** Python, FastAPI
- **AI:** Google Gemini API (`gemini-2.5-pro`)
- **PDF Generation:** ReportLab
- **Frontend:** Vanilla HTML, CSS, JavaScript
- **Hosting:** Render (Web Service)

---

## Prerequisites

- Python 3.9+
- A Google Gemini API key

---

## Installation

**1. Clone the repository**
```bash
git clone https://github.com/devanshi80/sbdc_chatbot.git
cd sbdc_chatbot
```

**2. Create and activate a virtual environment**
```bash
python -m venv venv
source venv/bin/activate        # Mac/Linux
venv\Scripts\activate           # Windows
```

**3. Install dependencies**
```bash
pip install -r requirements.txt
```

**4. Set up environment variables**

Create a `.env` file in the root directory:
```
GEMINI_API_KEY=your_api_key_here
```

---

## Running Locally

```bash
uvicorn main:app --reload
```

The app will be available at `http://127.0.0.1:8000`.

---

## Notes
- Recommendation generation typically takes 15–40 seconds depending on the Gemini model used
- If the site is not reflecting recent changes, do a hard refresh (`Cmd+Shift+R` on Mac, `Ctrl+Shift+R` on Windows)
